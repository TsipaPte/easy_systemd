# Гайд на создание systemd-служб

В этом репозитории я размещаю свой авторский гайд по созданию systemd-служб. Я старался написать его понятным и живым языком, используя эмодзи и юмор

## Где найти этот гайд

Данный гайд размещён в файле `GUIDE.txt` этого проекта. Учтите, что я писал его в Obsidian (и использовал его специфичный синтаксис), поэтому рекомендуется использовать именно его для просмотра данного файла

## Почему в формате .txt, а не .md?

Я пытался разместить его на GitHub в MarkDown-формате, однако, GitHub не поддерживает множество специфичных конструкций Obsidian (типа спойлеров, цветных блоков и т.д.)

## Как посмотреть этот гайд максимально комфортно?

1. Скачайте [Obsidian](https://obsidian.md/)
2. Создайте хранилище и перейдите в него
3. Скачайте `GUIDE.txt` и перекиньте его в Ваше хранилище Obsidian
4. Переименуйте `GUIDE.txt` в `GUIDE.md`
5. Наслаждайтесь просмотром!
